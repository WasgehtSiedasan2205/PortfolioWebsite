# Audio

Drop your tracks here. The player in `index.html` expects:

| File           | Title                    |
| -------------- | ------------------------ |
| `track-01.mp3` | Ocean World — Main Theme |
| `track-02.mp3` | Undertow                 |
| `track-03.mp3` | Breach                   |
| `track-04.mp3` | Escape Velocity          |

To add, rename or reorder tracks, edit the `<li class="track">` entries in the
Audio section of `index.html` (`data-src`, `data-title`, `data-ctx` and the
duration text). Missing files are shown as "missing" instead of breaking the page.

Tip: MP3 at 192–256 kbps or OGG/Opus keeps the page light.
